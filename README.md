## Keybinds

### General
- **Mod toggle**: Right ALT
- **Toggle Stealth Mode**: Not Bound

### Profiles (0.1.6+)

- **First Bar Profile**: Not Bound
- **Next Bar Profile**: Not Bound
- **Previous Bar Profile**: Not Bound
- **Random Bar Profile**: Not Bound
